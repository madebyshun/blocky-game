Deploy BaseCity Blockies

Owner tool: deploys the BaseCity Blockies (BCB) contract on Base from your browser wallet. Run it once.

1. Wallet

Use a browser wallet (MetaMask, Rabby, Coinbase Wallet extension): the dev wallet that will own the contract.

2. Claim signer

The server signs claims with this key (Vercel env CLAIM_SIGNER_KEY); the contract only accepts its signatures. Generate one here, or paste the address of a key you already made.
